# 🎲 Lucky_Chess

**Шахматы с кубиком - уникальная игра, где каждый ход определяется броском кубика с 99 гранями!**

## 📖 Описание

Lucky_Chess - это инновационная версия классических шахмат, где удача играет ключевую роль. Перед каждым ходом игрок бросает кубик с 99 гранями, и выпавшее число определяет, какой эффект будет применён. От потери фигур до режима бога - каждое число уникально!

## ✨ Особенности

- ♟️ **Полные правила шахмат**: рокировка, взятие на проходе, превращение пешки
- 🎲 **99 уникальных эффектов** кубика
- 👥 **3 режима игры**: с другом, с ботом, онлайн (в разработке)
- ❄️ **Система заморозки** фигур
- ✨ **Воскрешение** съеденных фигур
- 🕵️ **Кража** фигур противника
- ⏰ **Машина времени** - отмена хода
- 🌟 **Режим Бога** - двойной ход
- 💀 **Апокалипсис** - заморозка всех фигур врага
- 👑 **Ультиматум** - уничтожение всех фигур врага
- 🏆 **Мгновенная победа**
- 🔊 **Звуковые эффекты**
- 🏅 **Система достижений**
- 📱 **Адаптивный дизайн**

## 🎮 Как играть

1. Выберите режим игры
2. Бросьте кубик (число от 1 до 99)
3. Прочитайте эффект, который выпал
4. Сделайте ход согласно эффекту
5. Побеждает тот, кто поставит мат королю противника!

## 🛠️ Установка

### Локальный запуск
1. Скачайте все файлы
2. Откройте `index.html` в любом браузере
3. Играйте!

### Онлайн (GitHub Pages)
1. Создайте репозиторий на GitHub
2. Загрузите файлы
3. Включите GitHub Pages в настройках
4. Игра будет доступна по ссылке
